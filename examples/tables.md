# Tables

| Renderer | Input | Output |
| :--- | :---: | ---: |
| Markdown | CommonMark | Styled terminal blocks |
| Formula | LaTeX | Typeset PNG on Kitty |
| Media | Local asset | Terminal image |

| Formatting | Example | Expected |
| --- | --- | --- |
| Strong | **bold** | visible emphasis |
| Code | `const x = 1` | fixed-width source |
| Link | [OpenTUI](https://github.com/anomalyco/opentui) | link label |

The table is deliberately separate from math so it stays on OpenTUI's native
Markdown renderer.
